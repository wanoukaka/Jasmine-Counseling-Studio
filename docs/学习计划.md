## 学习阶段（共 6 周）

### 第1周：伦理原则与框架
**核心问题：** 心理咨询为什么要讲伦理？

**推荐阅读材料：**
- 《中国心理学会伦理守则》全文（必读）
- 《精神卫生法》相关条款
- 书籍：《心理咨询与治疗伦理》（Hill Gloria，豆瓣9.1）

**学习产出：**
- 理解4大伦理原则
- 能够举出违反伦理的案例

---

### 第2周：知情同意
**核心问题：** 第一次见面怎么开口说"我们签个知情同意书"？

**重点内容：**
- 知情同意的本质是"过程"，不是一张纸
- 告知内容：费用、保密范围、预约取消、咨询目标
- 口头同意 vs 书面同意
- 来访者理解能力有限时怎么办
- **实操练习：** 写出自己版知情同意告知话术（3分钟版本）

**练习任务：**
```
📝 任务：写一段3分钟的知情同意口头告知
包括：
1. 自我介绍和专业背景
2. 咨询目标和方式的简要说明
3. 保密原则和保密例外
4. 双方权利（来访者可随时提问/终止）
5. 费用和预约取消政策
```

---

### 第3周：保密原则
**核心问题：** 什么情况可以打破保密？怎么做？

**重点内容：**
- 保密是默认，不是例外
- 保密例外4种情况的具体判断
- 突破保密时的"最小必要"原则
- 未成年人保密的特殊处理
- 来访者要求复印病历/记录时怎么办

**情景讨论：**
```
🧠 情景1：
"王女士说她的丈夫有家暴倾向，请咨询师保密。但她儿子（12岁）目睹了这一切。学校老师问咨询师'孩子家里发生了什么'，咨询师该怎么办？"

🧠 情景2：
"来访者在视频咨询中透露自己有自杀计划，但拒绝提供具体信息，说'你会告诉别人吗？'咨询师该怎么回应？"

🧠 情景3：
"法院发函要求咨询师提交某来访者的全部咨询记录，咨询师该怎么办？"
```

---

### 第4周：专业边界与双重关系
**核心问题：** 朋友的朋友来咨询怎么办？收了礼物怎么办？

**重点内容：**
- 双重关系的危害（剥削风险、损害客观性）
- 现实中的灰色地带处理（偶遇、转介）
- 礼物处理的3个判断标准
- 网络时代的新边界问题（加微信、朋友圈互动）

**实操原则：**
```
礼物处理决策树：
礼物价值多少？ → 超过当地普通社交标准？
  ↓是              ↓否
拒绝并说明原因    考虑是否影响专业关系
         ↓影响
       建议转介
```

---

### 第5周：记录、档案与网络咨询伦理
**重点内容：**
- 个案记录的书写规范（避免"评判性语言"）
- 档案保存与销毁标准
- 视频咨询的特殊注意事项
- 平台选择（数据安全）

**练习：修改以下记录语言**
```
❌ 原始："来访者很神经质，说话语无伦次"
✅ 修改："来访者表达流畅度有所下降，谈话中有停顿，语调偏低"
```

---

### 第6周：整合与案例督导
**学习方式：** 结合真实案例（脱敏后）讨论

**案例督导讨论模板：**
```
案例中涉及的伦理议题：___________
涉及的伦理条款：___________
各方利益相关者：___________  
我的决定：___________
依据：___________
如果我不确定，我会：___________
```
