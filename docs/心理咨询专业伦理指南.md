# 心理咨询专业伦理指南
> 基于《中国心理学会临床与咨询心理学工作伦理守则》（2018版）| 玩偶卡卡整理 🧸

---

## 一、核心伦理原则（四大原则）

| 原则 | 含义 | 一句话 |
|------|------|--------|
| **善行** | 保障来访者福祉，不伤害 | 做对来访者有益的事 |
| **无害** | 避免造成心理/身体伤害 | 最小化一切风险 |
| **尊重** | 尊重来访者自主权、隐私 | 来访者自己做决定 |
| **诚信** | 诚实、真实、不欺骗 | 对来访者诚实 |

---

## 二、知情同意（最容易被忽略的第一步）

### 2.1 必须在咨询开始前告知来访者：

```
□ 咨询的目标、方法和预期效果
□ 咨询的局限性
□ 咨询的次数和频率
□ 收费标准和方式
□ 咨询师的专业背景和资质
□ 来访者的权利
□ 预约、取消和改期的规定
```

### 2.2 保密原则

**保密内容（所有）：**
- 来访者告知的所有个人信息
- 咨询中讨论的内容
- 咨询记录、测评结果
- 来访者的影像/录音（需额外同意）

**保密例外（只有这些情况可以突破保密）：**

| 情况 | 说明 |
|------|------|
| 🔴 来访者有伤害自己/他人的严重风险 | 自杀倾向、杀人计划 |
| 🔴 疑似虐待老人/儿童 | 发现疑似虐待情况 |
| 🔴 法庭要求 | 法律强制要求时 |
| 🔴 来访者书面同意 | 必须有具体范围的书面授权 |

**关键点：** 一旦突破保密，必须在最小必要范围内行动，且尽可能告知来访者。

### 2.3 未成年人保密
- 16岁以下来访者，原则上保密
- 但需告知监护人：涉及伤害自己/他人、虐待/被虐待的情况
- 建议：与未成年人工作前，书面告知监护人保密范围和例外

## 三、专业边界与双重关系

**双重关系（严格禁止）：**
- ❌ 与来访者发生性/浪漫关系
- ❌ 与来访者有商业/经济往来（超标准收费除外）
- ❌ 给来访者提供私人联系方式（紧急情况除外）
- ❌ 收受来访者贵重礼物
- ❌ 与来访者发展友谊/社交关系
- ❌ 给家人/朋友提供心理咨询

**偶遇原则：** 如果在非咨询场合遇到来访者，由咨询师决定如何应对，通常应简短、保持界限。

**礼物问题：**
- 小礼物（象征性的）→ 可以接受
- 贵重礼物 → 拒绝，说明原因
- 原则：礼物不能影响咨询的专业性

---

## 四、来访者权利

每个来访者在咨询中享有：

| 权利 | 说明 |
|------|------|
| 知情同意权 | 有权了解咨询的所有方面 |
| 隐私权 | 保密是默认，除非例外 |
| 自主权 | 有权决定自己的事情 |
| 选择权 | 有权选择咨询师、更换咨询师 |
| 拒绝权 | 有权随时终止咨询 |
| 申诉权 | 对咨询过程不满有投诉渠道 |

---

## 五、预约与取消伦理

**取消政策（建议纳入知情同意书）：**

```
建议标准：
- 预约后24小时内取消：收取50%费用
- 预约后12小时内取消：收取100%费用
- 来访者未到（No-show）：收取100%费用
- 紧急情况：可酌情减免
```

**理由：** 咨询师的时间是专业资源，空档意味着无法帮助另一位需要的人。

## 六、个案记录与档案伦理

**记录原则：**
- 记录应**客观、简洁、专业**
- 避免主观评判语言（如"来访者很神经质"）
- 使用描述性语言（如"来访者报告睡眠困难，情绪低落"）

**档案存储：**
- 纸质档案：上锁保管
- 电子档案：加密存储，有访问权限控制
- **云端存储需确保符合《个人信息保护法》**

**保存期限：**
- 通常至少保存 5 年（不同地区规定不同）
- 未成年人个案：年满18岁后再保留至少 3 年

**销毁：** 销毁时必须确保信息不可恢复

---

## 七、督导中的伦理

**被督者（咨询师）的责任：**
- 向督导师如实报告个案情况
- 隐藏来访者可识别信息（脱敏）
- 督导内容同样保密

**督导师的责任：**
- 对被督者提供的内容保密
- 不提供超越自身能力的督导
- 发现被督者重大伦理问题，必须处理

---

## 八、网络/视频咨询的特殊伦理

**额外注意事项：**

| 场景 | 风险点 | 处理方式 |
|------|--------|---------|
| 视频咨询 | 第三方平台隐私 | 使用专业加密平台，告知来访者风险 |
| 录音录像 | 必须书面同意 | 录音前必须明确告知用途 |
| 紧急情况 | 无法立刻到达 | 提前收集来访者紧急联系人信息 |
| 平台稳定性 | 技术中断 | 约定备用联系方式 |
| 地理边界 | 跨省咨询 | 注意当地法规，可能需要备案 |

## 九、常见伦理红线（绝对不能碰）

```
🚨 与来访者发生性关系（终身禁止执业）
🚨 伪造咨询记录
🚨 未经同意录音录像
🚨 泄露来访者隐私（保密例外情况除外）
🚨 超范围服务（如给朋友的孩子做咨询）
🚨 虚假宣传资质
🚨 与来访者有商业往来
```

---

## 十、伦理决策流程（遇到困惑时用）

```
Step 1: 识别伦理问题
         ↓
Step 2: 查阅《伦理守则》相关条款
         ↓
Step 3: 考虑所有相关方利益（来访者、公众、自身）
         ↓
Step 4: 咨询同事/督导师
         ↓
Step 5: 做出决定并记录过程
         ↓
Step 6: 事后复盘
```
