## 四、项目部署

### 1. 上传代码

```bash
# 方式一：Git 克隆
cd /var/www/
git clone https://github.com/wanoukaka/Jasmine-Counseling-Studio.git
cd Jasmine-Counseling-Studio

# 方式二：SCP 上传
scp -r ./Jasmine\ Counseling\ Studio/ user@server:/var/www/
```

### 2. 安装依赖

```bash
cd server
npm install
```

### 3. 配置环境变量

```bash
# 创建生产环境配置文件
cat > .env.production << EOF
NODE_ENV=production
PORT=3001
DATABASE_PATH=../db/jasmine.db
EOF
```

### 4. 启动服务

```bash
pm2 start server/index.js --name jasmine
pm2 save
pm2 startup
```

### 5. Nginx 反向代理配置

```nginx
# /etc/nginx/sites-available/jasmine
server {
    listen 80;
    server_name jasminepsych.cn www.jasminepsych.cn;

    # 静态文件
    location / {
        root /var/www/Jasmine-Counseling-Studio/h5;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # API 代理
    location /api {
        proxy_pass http://127.0.0.1:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }

    # 管理后台
    location /admin {
        alias /var/www/Jasmine-Counseling-Studio/client;
        try_files $uri $uri/ /admin/index.html;
    }
}
```

```bash
sudo ln -s /etc/nginx/sites-available/jasmine /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```
